## 四、【重要坑】sudoers 里的冒号必须转义
`/sys/class/powercap/intel-rapl:0/energy_uj` 中的 `:` 在 sudoers 里是保留字符，
未转义会写坏 `/etc/sudoers.d/*` → **sudo 全局失效**（连 `sudo -v` 都报语法错误）。
正确写法：

```
ll ALL=(root) NOPASSWD: /usr/bin/cat /sys/class/powercap/intel-rapl\:0/energy_uj
```

规范流程（务必照做）：
```bash
printf '...\n' > /tmp/x      # 先写临时文件
visudo -cf /tmp/x            # 校验通过才落盘
install -m 0440 -o root -g root /tmp/x /etc/sudoers.d/<name>
visudo -c                    # 落盘后整体复检
```
本次因未转义写坏过一次，sudo 全挂；因 root 口令不可用且 `pkexec` 需要 polkit 交互，
最终用 `pkttyagent -p $$ & pkexec /bin/rm -f /etc/sudoers.d/dsh-rapl`（pty 内输入 ll 自己的口令）才修回来。
**恢复手法留档**：
```bash
{ sleep 3; printf '<ll口令>\n'; sleep 4; } | script -qec \
  'pkttyagent -p $$ >/tmp/pktty.log 2>&1 & sleep 1; /usr/bin/pkexec /bin/rm -f /etc/sudoers.d/<坏文件>; echo RC=$?' /dev/null
```
